# 基于C语言的员工人事综合管理系统
## 项目简介
本项目为面向小型企业人事管理的控制台员工人事综合管理系统，基于 C 语言、模块化多文件编程，借助 VS Code完成开发。系统设置管理员与普通员工两类权限，涵盖员工档案、登录注册、考勤打卡、请假审批、薪资核算五大模块；采用单链表结合本地 txt 文件保存数据，无需数据库，重启数据可保留。

## 所用技术
链表、队列的增删改查操作，文件 IO 数据读写，系统时间处理，模块化多文件开发，基于角色的权限控制。

## 核心功能
搭建双角色权限体系，区分管理员与普通员工；实现员工档案信息增删改查，支持上下班打卡考勤、请假申请与审批流程；可自动统计出勤数据，完成薪资核算；采用本地文本文件持久化存储，保障程序重启后数据保留。
